# web-programming-2026-artemijs-stanko

Web programmēšanas kursa semestra darbu repozitorijs.

## Nedēļas

- [`week01-tailwind`](./week01-tailwind) — CampusFlow pāreja no tradicionālā CSS uz Tailwind CSS
  (Vite + Tailwind CSS 4).
- [`week02-typescript`](./week02-typescript) — CampusFlow datu vadīta versija ar TypeScript,
  formu un `localStorage` saglabāšanu.
- [`week03-api`](./week03-api) — CampusFlow ar datiem no JSON API, ielādes stāvokļiem un
  laikapstākļiem no Open-Meteo.
- [`week04-react`](./week04-react) — CampusFlow React versija ar komponentēm un tipizētiem
  props; datu slānis pārnests no 3. nedēļas bez izmaiņām.
