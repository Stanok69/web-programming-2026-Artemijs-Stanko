# Mākslīgā intelekta izmantošana

**Vārds, uzvārds: Artemijs Stanko**
**Izmantotais(-ie) MI rīks(-i):** GitHub Copilot

## Kam es izmantoju mākslīgo intelektu?

- Lai saprastu, kā CSS pārveidot uz Tailwind klasēm.
- Lai palīdzētu salabot projekta build komandu.
- Lai pārbaudītu, vai projekts strādā.

## Kuru kodu vai konfigurāciju būtiskā apjomā ģenerēja mākslīgais intelekts?

- Daļa src/app.js koda un Tailwind klašu.

## Kuru kodu vai konfigurāciju es uzrakstīju pats/pati vai būtiski pārveidoju?

- Es pats pārbaudīju lapas izskatu un pogu darbību.
